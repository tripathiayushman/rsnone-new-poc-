RSN ONE — image drop zone
=========================

The 34 handoff HTML files reference every photograph from this folder.
Until a file exists here under the exact name the HTML asks for, that image
renders as a labelled dashed box. Nothing else needs to change — drop the
file in, reload the page.

What to supply, and under what names: ../IMAGE-MANIFEST.md
60 slots in total.
